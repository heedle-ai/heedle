# heedle

heedle-ai in one binary: write programs of AI steps, run them on Temporal, and keep every run in Git.

```sh
go run . up        # starts Temporal, a worker and the UI; open http://127.0.0.1:8090
```

See the [wiki](https://github.com/heedle-ai/heedle/wiki) for installing, `heedle up`, and the commands.
